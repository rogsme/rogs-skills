# Writing

Skills for prose that people read: style that does not read as machine-written, controlled technical English, and messages ready to paste into chat. Each one runs on its own.

## User-invoked

- [wait-what](./wait-what/SKILL.md): when the last message did not land, have the agent re-pitch it with some context, in the glossary's terms and in Simplified Technical English.
- [to-questionnaire](./to-questionnaire/SKILL.md): turn a decision you cannot answer alone into a Markdown questionnaire for the person who holds the missing knowledge.

## Model-invoked

- [avoid-ai-tropes](./avoid-ai-tropes/SKILL.md): write, proofread or deep-rewrite prose without the tells of machine-written text, keeping its meaning and the author's voice.
- [asd-ste100](./asd-ste100/SKILL.md): write or rewrite technical documentation in ASD-STE100 Simplified Technical English (Issue 9).
- [chat-paste](./chat-paste/SKILL.md): turn a message into a local preview page with buttons that copy it as Slack or Teams rich text.
